A new name (D194): OneVoid, the OneBlock add-on. How it works is unchanged. As the owner asked (D196), it keeps no old names.

## Installing over the previous version

With the server stopped:
1. Rename its plugin folder to `plugins/OneVoid`. Islands, bells and teams are inside.
2. Move its LuckPerms permissions to the matching `onevoid.*` nodes.
3. Use `/onevoid` for its admin commands.
4. Install Mayor 0.5.0 at the same time: team invites check circles through Mayor.

Unit tests pass. The rename was checked with the other plugins on a throwaway server.
